# הפיטסרי של אוסקר – האתר

אתר דמיוני שנוצר בשביל הכיף: הפיטסרי לא קיים באמת, והאתר אומר את זה בפתיחה, באזור "בואו לבקר", בסל ובתחתית העמוד.

אתר בעמוד אחד, בעברית, עם קרואסון תלת־ממדי שזז לאורך הגלילה, תפריט עם סל קניות, והמשחק של אוסקר.

## איך פותחים
- הכי פשוט: לחיצה כפולה על `index.html`.
- או כשרת מקומי: `npm run serve` ואז לפתוח את http://localhost:5178

## איך משנים פרטים
כל הפרטים נמצאים בקובץ אחד: **`data.js`**
כתובת, שעות פתיחה, טלפון, מייל, שמות, תיאורים ומחירים (כולם מומצאים).
אחרי שמירה מרעננים את הדף. לא צריך לבנות כלום מחדש.

> הסל עובד לתצוגה בלבד: "שליחת ההזמנה" לא שולחת כלום, רק מסבירה שהפיטסרי דמיוני ומזמינה לשחק במשחק.

## המשחק
הכפתור "שחקו במשחק שלי" פותח את המשחק מתוך התיקייה `game/`, שהיא עותק של `C:\dev\OscarPastry`.
כשהמשחק מתעדכן: `npm run sync-game`

## פקודות למפתחים
| פקודה | מה היא עושה |
|---|---|
| `npm run build` | בונה את `app.js` מהקוד שב־`src/` |
| `npm run photos` | מצלם מחדש את כל תמונות התפריט מהמודלים התלת־ממדיים (`img/products/`) |
| `npm run sync-game` | מעתיק את הגרסה העדכנית של המשחק |
| `npm run serve` | שרת מקומי על פורט 5178 |

הקרואסון בנוי כולו בקוד (`src/croissant.js`), בלי קבצי מודל. `src/stage.js` מחבר אותו לגלילה.
